# Levty Team 1 - Frontend

Frontend desenvolvido com **React** e **Vite**.

## 📋 Pré-requisitos

Antes de iniciar, certifique-se de possuir instalado em sua máquina:

* Node.js (versão 18 ou superior)
* npm (instalado junto com o Node.js) ou outro gerenciador de pacotes compatível

Para verificar se está tudo instalado:

```bash
node -v
npm -v
```

---

## 🚀 Clonando o projeto

Clone o repositório:

```bash
git clone https://github.com/marcelobelisario/levty-team-1.git
```

Entre na pasta do projeto:

```bash
cd levty-team-1
```

---

## 📦 Instalando as dependências

Execute o comando abaixo para instalar todas as dependências do projeto:

```bash
npm install
```

ou, caso utilize Yarn:

```bash
yarn
```

---

## ▶️ Executando o projeto

Após instalar as dependências, inicie o servidor de desenvolvimento:

```bash
npm run dev
```

ou

```bash
yarn dev
```

O Vite iniciará o projeto e exibirá um endereço semelhante a:

```text
Local:   http://localhost:5173/
```

Abra esse endereço no navegador para acessar a aplicação.
